KITOUT Declarative setup for your Mac

Mac setup as reviewed state

Your Mac. Defined.

Kitout checks packages, apps, repos, file copies, login shell, folders, and defaults against a YAML file before it changes anything.

Open GitHub

Workflow

Define, check, preview, apply.

  1. 1.

    Define

    kitout init 
    version: 1

brew:
  packages:
    - git
    - asdf
    - pnpm
    - gh

casks:
  - ghostty
  - visual-studio-code

repos:
  - path: ~/code/example-project
    url: git@github.com:example/example-project.git
    branch: main

symlinks:
  - source: ~/dotfiles/home/zshrc
    target: ~/.zshrc
    replace: true

login_shell:
  path: homebrew:fish
  add_to_etc_shells: true

    Create the home config, or keep ./kitout.yaml in a setup repo. If both config files exist, bring --config.

    Kitout refuses ambiguous config paths until you choose one.

Safety model

Preview first. Apply after review.

Status never makes changes, dry-run never makes changes, and shell commands only run when they are listed in config and approved. Shell commands, copy replacements, symlink replacements, and login-shell changes are confirmation-gated unless --yes is passed. When ./kitout.yaml and ~/.config/kitout/kitout.yaml both exist, Kitout stops and asks for --config.

Install

Start with the same commands in the README.

Public release path

brew tap vwall/kitout
brew install kitout

Build from source

go install ./cmd/kitout

Setup repo first pass

cd ~/code/setup
kitout doctor --config ./kitout.yaml
kitout status --config ./kitout.yaml
kitout apply --config ./kitout.yaml --dry-run
Kitout is Mac-first, local-first, and written in Go.
