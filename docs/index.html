KITOUT Declarative setup for your Mac View on GitHub

Mac setup as reviewed state

Your Mac. Defined.

Kitout checks packages, apps, repos, dotfiles, folders, and defaults against a YAML file before it changes anything.

Open GitHub brew install kitout

Workflow

Define, check, preview, apply.

  1. 1.

    Define

    kitout init
    version: 1 brew:   packages:     - git repos:

    Create the home config, or keep ./kitout.yaml in a setup repo. If both config files exist, bring --config.

  2. 2.

    Check

    kitout doctor
    macOS Homebrew Git config

    Confirm Homebrew, Git, shell environment, config validity, and path permissions before touching resources.

  3. 3.

    Inspect

    kitout status
    ok brew: git miss cask: ghostty chg symlink: ~/.zshrc

    See satisfied, missing, changed, skipped, and failed resources in one structured report.

  4. 4.

    Preview

    kitout apply --dry-run
    dry-run install cask ghostty dry-run clone ~/code/app no shell command will run

    Inspect installs, clones, symlinks, defaults, and approved shell commands with no filesystem changes.

  5. 5.

    Apply

    kitout apply
    Applying... Complete

    Kitout applies only missing or changed resources. Rerun status and the Mac matches the declared state.

Real output

Selected config. Electric output.

Safety model

Preview first. Apply after review.

Status never makes changes, dry-run never makes changes, and shell commands only run when they are listed in config and approved. When ./kitout.yaml and ~/.config/kitout/kitout.yaml both exist, Kitout stops and asks for --config.

Install

Start with the same commands in the README.

Public release path

brew tap vwall/kitout
brew install kitout

Build from source until the tap is published

go install ./cmd/kitout

Setup repo first pass

cd ~/code/setup
kitout doctor --config ./kitout.yaml
kitout status --config ./kitout.yaml
kitout apply --config ./kitout.yaml --dry-run
Kitout is Mac-first, local-first, and written in Go. github.com/vwall/kitout
