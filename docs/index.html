YAML that explains itself.

The MVP keeps resources explicit: packages, casks, directories, symlinks, repositories, macOS defaults, security checks, system prerequisites, SSH keys, and approved shell commands.

kitout.yaml 
version: 1

brew:
  taps:
    - vwall/kitout
  packages:
    - git
    - gh
    - asdf
  casks:
    - ghostty
    - visual-studio-code

directories:
  - ~/.config

repos:
  - path: ~/code/example
    url: git@github.com:example/example.git
    branch: main

symlinks:
  - source: ~/dotfiles/zshrc
    target: ~/.zshrc
    replace: true

security:
  filevault:
    required: true
  firewall:
    enabled: true

ssh:
  keys:
    - path: ~/.ssh/id_ed25519
      type: ed25519
brew

Install packages after checking the current Homebrew state.

cask

Confirm app presence before installing desktop software.

repo

Clone or verify repositories at declared local paths.

symlink

Replace links only when config explicitly allows it.

security

Require FileVault and manage firewall state with typed checks.

ssh

Generate declared SSH keypairs without shell setup blocks.

shell

Run only commands that are explicitly listed in YAML.

Status names the current state

Every resource reports satisfied, missing, changed, skipped, or failed.

Apply starts from the same plan

Only resources that need work are applied, and risky changes ask first.

Doctor explains blockers

Prerequisites fail early, before resource checks become noisy.

fail: Homebrew Homebrew is not available

fix: Install Homebrew, then rerun kitout doctor.

fail: Path permissions 1 configured write target(s) may not be writable

fix: Fix ownership or permissions for the listed paths, then rerun kitout doctor.

Safety rules by default.

Kitout keeps inspection and mutation separate, so each risky action stays visible before it touches the machine.

  • status Never makes changes.
  • preview Never writes to the filesystem.
  • shell Runs only commands explicitly listed in config.
  • homebrew Is never auto-installed without an explicit choice.
  • config Ambiguous paths require an explicit choice.
  • files Are never deleted or overwritten unless config allows it.
