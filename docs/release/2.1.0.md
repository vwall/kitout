# Kitout 2.1.0 Release Notes

Kitout 2.1.0 adds agent-friendly inspection commands for understanding a setup
config before making changes. The release keeps the stable `version: 1` config
schema from 2.0.0.

## Highlights

- Use `kitout context` to list declared resources, safe commands, commands that
  require approval, and setup guidance without checking live machine state.
- Use `kitout explain <resource-id>` to check one configured resource, report
  its planned action, call out risky apply behavior, and show related commands.
- Request JSON output from the new commands with `--json` for stable
  machine-readable reports.
- Agent-facing docs now describe how to inspect configs, gather evidence with
  status or dry-run output, and avoid unintended machine changes.
- The Homebrew formula template points at the `v2.1.0` release artifacts.

## New Commands

Show declared resources and safe next steps:

```sh
kitout context --config ./kitout.yaml
kitout context --config ./kitout.yaml --json
```

Explain one configured resource:

```sh
kitout explain directory:$HOME/code --config ./kitout.yaml
kitout explain directory:$HOME/code --config ./kitout.yaml --json
```

Both commands are inspection-oriented. `kitout context` does not check live
resource state, and `kitout explain` builds a one-resource plan without applying
changes. Status checks and dry-runs remain the evidence source before any real
apply run.

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `2.0.0` configs continue to load without required changes.
- Top-level `casks` remains removed; use `brew.casks`.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_2.1.0_darwin_arm64.tar.gz`
- `kitout_2.1.0_darwin_amd64.tar.gz`
- `kitout_2.1.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
