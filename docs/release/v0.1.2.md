# Kitout 0.1.2 Release Notes

Kitout 0.1.2 is a patch release focused on safer config discovery, clearer
release tooling, and refreshed documentation.

## Changes

- `kitout status`, `kitout apply`, and `kitout doctor` now require `--config` when both `./kitout.yaml` and `~/.config/kitout/kitout.yaml` exist.
- `./kitout.yaml` is still used automatically when it is the only implicit config file.
- CLI help, README, setup docs, config docs, and install docs now describe the explicit config selection behavior.
- Added `--color` and `--no-color` output controls for more predictable terminal and automation output.

## Release Tooling

- Added release-note preparation tooling and tests.
- Improved the macOS distribution smoke test.
- Normalized `TMPDIR` handling in the smoke test so path comparisons work when `TMPDIR` already ends with `/`.

## Documentation

- Added and refreshed the documentation site, including screenshots, visual assets, and GitHub Pages publishing support.
- Updated installation and distribution docs for the current release flow.

## Distribution

The tagged release workflow publishes:

- `kitout_0.1.2_darwin_arm64.tar.gz`
- `kitout_0.1.2_darwin_amd64.tar.gz`
- `kitout_0.1.2_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release assets.

## Upgrade

```sh
brew update
brew upgrade kitout
```
