# Kitout 0.1.1 Release Notes

Kitout 0.1.1 is a patch release for setup-repo ergonomics.

## Changes

- `kitout status`, `kitout apply`, and `kitout doctor` now select `./kitout.yaml` before `~/.config/kitout/kitout.yaml` when `--config` is not passed.
- CLI help, README, setup docs, and config docs now describe the local-first config lookup order.

## Upgrade

```sh
brew update
brew upgrade kitout
```
