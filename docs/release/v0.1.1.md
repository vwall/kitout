# Kitout 0.1.1 Release Notes

Kitout 0.1.1 is a patch release for safer setup-repo ergonomics.

## Changes

- `kitout status`, `kitout apply`, and `kitout doctor` now require `--config` when both `./kitout.yaml` and `~/.config/kitout/kitout.yaml` exist.
- `./kitout.yaml` is still used automatically when it is the only implicit config file.
- CLI help, README, setup docs, and config docs now describe the explicit config selection behavior.

## Upgrade

```sh
brew update
brew upgrade kitout
```
