# Kitout 2.0.0 Release Notes

Kitout 2.0.0 is a major release focused on safer fresh-Mac setup runs. It
removes the deprecated top-level cask config shape and adds the security,
system prerequisite, SSH key, and path-hardening work needed for broader
real-machine use.

## Highlights

- Require Homebrew cask apps under `brew.casks`; top-level `casks` is now
  rejected with migration guidance.
- Manage FileVault and macOS application firewall expectations with dedicated
  `security` resources.
- Check and apply system prerequisites for Xcode Command Line Tools and Rosetta.
- Generate missing Ed25519 SSH keypairs through the new `ssh.keys` resource.
- Report Homebrew freshness advisories without treating outdated formulae or
  casks as config drift.
- Reject duplicate resource IDs before planning work.
- Harden command execution and path handling for shell commands, implicit
  dependency checks, copies, symlinks, `.tool-versions`, SSH public keys, and
  login shell paths.
- The Homebrew formula template points at the `v2.0.0` release artifacts.

## Breaking Change

Move top-level casks:

```yaml
casks:
  - ghostty
```

under `brew.casks`:

```yaml
brew:
  casks:
    - ghostty
```

The YAML config schema field remains `version: 1`; `2.0.0` is the Kitout
release version. Configs that already use `brew.casks` do not need a schema
version change.

## New Resources

Security resources:

```yaml
security:
  filevault:
    required: true
  firewall:
    enabled: true
    stealth_mode: true
```

System prerequisite resources:

```yaml
system:
  xcode_command_line_tools:
    required: true
  rosetta:
    required: true
```

SSH key resources:

```yaml
ssh:
  keys:
    - path: ~/.ssh/id_ed25519
      type: ed25519
      comment: user@example.com
```

## Compatibility

- Existing configs that use `brew.casks` continue to load with `version: 1`.
- Existing configs that still use top-level `casks` must be migrated before
  upgrading.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_2.0.0_darwin_arm64.tar.gz`
- `kitout_2.0.0_darwin_amd64.tar.gz`
- `kitout_2.0.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
