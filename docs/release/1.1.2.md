# Kitout 1.1.2 Release Notes

Kitout 1.1.2 is a patch release for the 1.1.x line. It keeps the stable
`version: 1` config schema and improves first-run apply behavior on fresh Macs.

## Highlights

- `kitout apply` now applies independent missing or changed resources even when
  another resource cannot be planned yet.
- Failed or unknown resources remain visible in the final apply results and
  still make the command exit with code `4`.
- First-run and asdf documentation now explain that prerequisite resources can
  install in one pass, then dependent resources can apply on a later run.
- The Homebrew formula template points at the `v1.1.2` release artifacts.

## Compatibility

- No schema version bump is required.
- Existing `1.1.x` configs continue to load without changes.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_1.1.2_darwin_arm64.tar.gz`
- `kitout_1.1.2_darwin_amd64.tar.gz`
- `kitout_1.1.2_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
