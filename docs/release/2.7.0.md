# Kitout 2.7.0 Release Notes

Kitout 2.7.0 adds optional target prefixes for grouped symlinks, while keeping
the stable `version: 1` config schema from earlier 2.x releases.

## Highlights

- Add `target_prefix: "."` to a symlink group to map source paths such as
  `zshrc` and `config/ghostty` to `~/.zshrc` and `~/.config/ghostty`.
- Keep the source tree free of leading dots without repeating every symlink as
  an explicit `source` and `target` pair.
- Apply the prefix once to the complete relative target path, so
  `config/ghostty` becomes `.config/ghostty`, not `.config/.ghostty`.
- Reject prefixes that would make a target absolute or escape `target_root`.

## Grouped Symlink Target Prefixes

Use the new optional `target_prefix` field on a symlink group:

```yaml
symlink_groups:
  - source_root: ./home
    target_root: "~"
    target_prefix: "."
    paths:
      - zshrc
      - gitconfig
      - config/ghostty
      - config/nvim
```

Kitout expands this group into the following source-to-target mappings:

```txt
./home/zshrc          -> ~/.zshrc
./home/gitconfig      -> ~/.gitconfig
./home/config/ghostty -> ~/.config/ghostty
./home/config/nvim    -> ~/.config/nvim
```

Omit `target_prefix` to keep the existing behavior, where each relative path is
used below both `source_root` and `target_root` unchanged.

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `2.6.0` configs continue to load without required changes.
- Existing symlink groups behave exactly as before when `target_prefix` is
  omitted.
- Status checks and dry-runs still do not change the system.
- Symlink replacement still requires `replace: true` and confirmation for a
  real apply unless `--yes` is passed.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_2.7.0_darwin_arm64.tar.gz`
- `kitout_2.7.0_darwin_amd64.tar.gz`
- `kitout_2.7.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.
