# Kitout 1.0.0 Release Notes

Kitout 1.0.0 is the first stable public release for declarative macOS setup.
It establishes the stable `version: 1` YAML config schema, the core command
surface, and the initial Homebrew distribution path.

## Highlights

- Declare a Mac setup in YAML with Homebrew packages, casks, asdf tools,
  directories, file copies, symlinks, Git repositories, macOS defaults, and
  explicit shell commands.
- Check desired machine state with `kitout status`.
- Preview changes safely with `kitout apply --dry-run`.
- Apply missing or changed resources with `kitout apply`.
- Inspect local prerequisites with `kitout doctor`.
- Start from a validating starter config with `kitout init`.

## Stable Contracts

- Config schema `version: 1` is considered stable.
- `kitout status`, `kitout apply`, `kitout apply --dry-run`, `kitout doctor`,
  `kitout init`, and `kitout version` are the stable command surface.
- Status checks and dry-runs do not make changes.
- Apply remains idempotent and only changes resources declared in config.
- Risky actions, including shell commands, copy replacement, and symlink
  replacement, still require confirmation unless `--yes` is passed.

## Changes Since 0.1.1

- `kitout status`, `kitout apply`, and `kitout doctor` require `--config` when
  both `./kitout.yaml` and `~/.config/kitout/kitout.yaml` exist.
- `./kitout.yaml` is used automatically when it is the only implicit config
  file.
- Added `--color` and `--no-color` output controls for predictable terminal and
  automation output.
- Added release-note preparation tooling and tests.
- Added GitHub Pages documentation site assets and publishing workflow.
- Improved the macOS distribution smoke test.
- Normalized `TMPDIR` handling in the smoke test.

These changes include the prepared but unpublished `0.1.2` work.

## Distribution

The tagged release workflow publishes:

- `kitout_1.0.0_darwin_arm64.tar.gz`
- `kitout_1.0.0_darwin_amd64.tar.gz`
- `kitout_1.0.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
