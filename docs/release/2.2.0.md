# Kitout 2.2.0 Release Notes

Kitout 2.2.0 adds repo-local agent guidance for private setup repositories. It
keeps the stable `version: 1` config schema from earlier 2.x releases.

## Highlights

- Use `kitout init --config ./kitout.yaml --agents` to create or update
  repo-local `AGENTS.md` guidance for coding agents.
- Existing `AGENTS.md` content is preserved; Kitout appends or refreshes only
  its marked section.
- Generated guidance points agents at safe context, status, dry-run, and doctor
  commands while warning against secrets, unrequested shell commands, and direct
  edits to managed `$HOME` targets.
- `kitout doctor --config ./kitout.yaml` now warns when the selected config is
  inside a Git repo and `AGENTS.md` is missing.
- The Homebrew formula template points at the `v2.2.0` release artifacts.

## Agent Guidance

Generate Kitout guidance in a setup repo:

```sh
kitout init --config ./kitout.yaml --agents
```

When the config already exists, Kitout leaves it unchanged and still creates or
updates `AGENTS.md`. When the config is inside a Git repo, the generated file is
placed at the repo root; otherwise it is placed next to the selected config.

The generated section is intentionally compact. It lists safe read-only and
dry-run commands, names the real apply command as approval-required, and reminds
agents to prefer Kitout resources over ad hoc shell scripts.

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `2.1.0` configs continue to load without required changes.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_2.2.0_darwin_arm64.tar.gz`
- `kitout_2.2.0_darwin_amd64.tar.gz`
- `kitout_2.2.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
