# Kitout 1.3.0 Release Notes

Kitout 1.3.0 adds `brew.casks` as the preferred Homebrew cask configuration
location while keeping compatibility with existing `version: 1` configs.

## Highlights

- Configure Homebrew cask apps under `brew.casks`, alongside `brew.taps` and
  `brew.packages`.
- Continue loading existing top-level `casks` entries for schema version 1.
- Show a deprecation warning when top-level `casks` is used, so configs can be
  migrated gradually.
- Reject configs that set both top-level `casks` and `brew.casks`, keeping the
  desired cask list unambiguous.
- The Homebrew formula template points at the `v1.3.0` release artifacts.

## Config

Use `brew.casks` for new configs:

```yaml
brew:
  taps:
    - homebrew/cask-fonts
  packages:
    - git
  casks:
    - ghostty
    - visual-studio-code
```

Older configs that use top-level `casks` still work:

```yaml
casks:
  - ghostty
```

Move those entries under `brew.casks` when convenient.

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `1.2.x` configs continue to load without required changes.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_1.3.0_darwin_arm64.tar.gz`
- `kitout_1.3.0_darwin_amd64.tar.gz`
- `kitout_1.3.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
