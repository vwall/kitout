# Kitout 1.1.1 Release Notes

Kitout 1.1.1 is a patch release for the 1.1.x line. It keeps the stable
`version: 1` config schema and focuses on release polish, starter config
defaults, and smoke-test coverage.

## Highlights

- `kitout status` now shows concise batched progress while fetching Homebrew
  package and cask lists.
- `kitout init` now creates `~/.codex/skills` in the active starter config and
  includes commented examples for copy and login-shell resources.
- The macOS distribution smoke test now exercises a temp-only directory copy
  apply and safe login-shell status/dry-run planning.
- The Homebrew formula template points at the `v1.1.1` release artifacts.

## Compatibility

- No schema version bump is required.
- Existing `1.1.0` configs continue to load without changes.
- Status checks and dry-runs still do not change the system.

## Distribution

The tagged release workflow publishes:

- `kitout_1.1.1_darwin_arm64.tar.gz`
- `kitout_1.1.1_darwin_amd64.tar.gz`
- `kitout_1.1.1_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
