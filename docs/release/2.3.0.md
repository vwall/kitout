# Kitout 2.3.0 Release Notes

Kitout 2.3.0 makes setup-repo workflows the default for `kitout init`, while
keeping the stable `version: 1` config schema from earlier 2.x releases.

## Highlights

- Plain `kitout init` now creates or uses `./kitout.yaml` in the current
  directory.
- Use `kitout init --home` when you want to create or use
  `~/.config/kitout/kitout.yaml`.
- `kitout init --agents` now pairs naturally with the local default by creating
  or using `./kitout.yaml` and generating repo-local `AGENTS.md` guidance.
- Use `kitout init --no-agents-warning` when a setup repo intentionally does
  not want an `AGENTS.md` file; Kitout records that preference in
  `.kitout/agent-guidance.yaml`.
- The Homebrew formula template points at the `v2.3.0` release artifacts.

## Init Defaults

Create a setup-repo config in the current directory:

```sh
kitout init
```

Create the home config explicitly:

```sh
kitout init --home
```

Generate agent guidance in a setup repo:

```sh
kitout init --agents
```

Disable the missing `AGENTS.md` doctor advisory without creating an agent file:

```sh
kitout init --no-agents-warning
```

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `2.2.0` configs continue to load without required changes.
- Existing explicit `kitout init --config <path>` workflows continue to work.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_2.3.0_darwin_arm64.tar.gz`
- `kitout_2.3.0_darwin_amd64.tar.gz`
- `kitout_2.3.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
