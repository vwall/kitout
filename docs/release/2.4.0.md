# Kitout 2.4.0 Release Notes

Kitout 2.4.0 adds an explicit upgrade workflow for managed Homebrew formulae
and casks, while keeping the stable `version: 1` config schema from earlier 2.x
releases.

## Highlights

- Use `kitout upgrade --dry-run` to preview outdated managed Homebrew formulae
  and casks without changing the machine.
- Use `kitout upgrade` to upgrade only outdated formulae and casks already
  declared in the selected Kitout config.
- Use `kitout upgrade --only brew` or `kitout upgrade --only cask` to narrow the
  upgrade scope.
- JSON output is available for upgrade planning and execution workflows.
- The documentation site has refreshed navigation, resource pages, and command
  examples for the current CLI surface.
- The Homebrew formula template points at the `v2.4.0` release artifacts.

## Upgrade Workflow

Preview managed Homebrew upgrades:

```sh
kitout upgrade --dry-run
```

Upgrade outdated managed formulae and casks:

```sh
kitout upgrade
```

Limit upgrades to formulae:

```sh
kitout upgrade --only brew
```

Limit upgrades to casks:

```sh
kitout upgrade --only cask
```

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `2.3.0` configs continue to load without required changes.
- `kitout apply` still installs missing managed Homebrew resources but does not
  upgrade outdated packages.
- Missing formulae and casks are skipped by `kitout upgrade` with guidance to
  run `kitout apply` first.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_2.4.0_darwin_arm64.tar.gz`
- `kitout_2.4.0_darwin_amd64.tar.gz`
- `kitout_2.4.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
