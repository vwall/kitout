# Kitout 1.2.0 Release Notes

Kitout 1.2.0 adds first-class Homebrew tap management to the stable
`version: 1` config schema and improves command failure reporting.

## Highlights

- Add Homebrew taps with the new `brew.taps` config section before installing
  dependent formulae.
- Use fully-qualified formula names such as `owner/repo/formula` when a tapped
  formula needs to be selected explicitly.
- See compact stderr/stdout summaries in human and JSON output when external
  commands fail.
- Updated docs examples and the site workflow view for the current resource set.
- The Homebrew formula template points at the `v1.2.0` release artifacts.

## New Resource

`brew.taps` ensures a Homebrew tap is available:

```yaml
brew:
  taps:
    - vwall/kitout
  packages:
    - vwall/kitout/kitout
```

Status checks read the existing Homebrew tap list without changing the system.
Apply runs `brew tap <name>` only for missing taps. Dry-runs report the planned
tap addition without mutating Homebrew.

## Compatibility

- No schema version bump is required; this is an additive `version: 1` release.
- Existing `1.1.x` configs continue to load without changes.
- Status checks and dry-runs still do not change the system.
- Kitout still does not install Homebrew automatically.

## Distribution

The tagged release workflow publishes:

- `kitout_1.2.0_darwin_arm64.tar.gz`
- `kitout_1.2.0_darwin_amd64.tar.gz`
- `kitout_1.2.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release
assets.

## Install

```sh
brew tap vwall/kitout
brew install kitout
```
