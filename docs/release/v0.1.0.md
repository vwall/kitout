# Kitout 0.1.0 Release Notes

Kitout 0.1.0 is the initial MVP release for declaring, checking, and applying a fresh Mac setup.

## Highlights

- Check desired machine state with `kitout status`.
- Preview changes safely with `kitout apply --dry-run`.
- Apply missing resources with `kitout apply`.
- Inspect local prerequisites with `kitout doctor`.
- Start from a validating YAML config with `kitout init`.
- Run from a setup repo with `./kitout.yaml` selected automatically before the home config.

## Supported Resources

- Homebrew packages
- Homebrew casks
- asdf plugins
- asdf `.tool-versions` entries
- directories
- symlinks
- grouped symlinks
- Git repositories
- macOS defaults
- explicit shell commands

## Distribution

The tagged release workflow publishes:

- `kitout_0.1.0_darwin_arm64.tar.gz`
- `kitout_0.1.0_darwin_amd64.tar.gz`
- `kitout_0.1.0_checksums.txt`

Homebrew tap installation should use the checksums from the exact GitHub release assets.

## Known Scope Limits

- macOS only for 0.1.0
- no automatic Homebrew installation
- no config includes or templates
- no secret management
- no plugin system
- no Borkfile compatibility
