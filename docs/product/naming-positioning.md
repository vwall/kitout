# Naming and Positioning

## Name

Kitout

## Why the name works

"Kit out" means to equip someone or something with what is needed for a purpose. That maps directly to the product.

Kitout equips a fresh Mac with the tools and configuration needed for development.

## Domain

The preferred domain is:

```txt
kitout.dev
```

## CLI command

The command should be:

```sh
kitout
```

## Repository name

Recommended repository names:

```txt
kitout
homebrew-kitout
kitout-docs
```

If using a Homebrew tap:

```txt
homebrew-tap
```

## Taglines

Recommended primary tagline:

```txt
Equip a fresh Mac with your apps, packages, repos, dotfiles, and defaults.
```

Shorter options:

```txt
Make a fresh Mac feel like home.
```

```txt
Declarative setup for your Mac.
```

```txt
Your Mac setup, checked and applied.
```

## Positioning

Kitout should not be positioned as just another dotfile manager.

Kitout should be positioned as:

> a Mac setup reconciler for developers

or:

> a declarative setup tool for developer machines

## Comparison language

Use this framing:

- Stow manages symlinks.
- Chezmoi manages dotfiles across machines.
- Bork inspired declarative machine assertions.
- Kitout manages a fresh Mac setup through a typed Go CLI and structured config.

## Words to use

## Words to avoid

- AI
- agent
- autonomous
- magic
- productivity platform
- cloud control plane
- endpoint management
- enterprise device management

## Naming caveat

The word "kitout" is also used in clothing and workwear contexts. That does not block this product direction because the developer domain and `.dev` positioning make the use case clear.

Before public release, run a proper trademark and package registry review.
